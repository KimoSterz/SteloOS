# SteloOS — SunoOS

Przeglądarkowy system operacyjny w jednym pliku (`index.html`).

- Menedżer okien: przeciąganie za pasek tytułu, zmiana rozmiaru z 8 kierunków, minimalizacja/maksymalizacja (dwuklik na pasku też działa), z-order
- Aplikacje: Filer (grid/lista/kolumny, szukanie) i Settings (motyw, akcent, tapeta, tint) + wyspy doku (QS, kalendarz, tryb aranżacji z drag &drop, zapis w `localStorage`)
- Logo: `assets/suno-logo.jpg`

Start: otwórz `index.html` w przeglądarce albo włącz GitHub Pages.
